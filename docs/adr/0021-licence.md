# 0021. Apache-2.0 and attribution

- Status: accepted (2026-11-20, Approval 2)

## Context
The rules require an OSI licence visible in the repo's About; CC-BY data needs attribution.

## Decision
Apache-2.0 (patent grant). A NOTICE file and an in-app attributions page for chromium-i18n address metadata and GeoNames (CC-BY 4.0) and Japan Post data. Bank names appear as text, with no logos. ISO 20022 XSDs are committed only if their licence allows (M0-04).

## Alternatives considered
MIT (no patent grant).

## Consequences
Cost to reverse: Low. See [architecture](../architecture.md).
