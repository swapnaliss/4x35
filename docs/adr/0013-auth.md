# 0013. Invite-only accounts, sessions and scoped tokens

- Status: accepted (2026-11-20, Approval 2)

## Context
R8; addresses are personal data; judges need their own workspaces.

## Decision
Email + password (argon2id via @node-rs/argon2). Server sessions in Postgres (httpOnly, Secure, SameSite=Lax) with a CSRF token on mutations. Accounts by invite only; password reset by an admin-issued one-time link (no email provider). Roles owner and reviewer enforced in middleware and in a workspace-scoped repository layer; an authZ matrix test covers every endpoint. API tokens: prefix `4x35_`, hashed, scoped, expiring, revocable. Optional four-eyes per workspace (the uploader cannot approve). Per-workspace quotas. Judges get sandbox workspaces (cloned seed, nightly reset) with credentials in Devpost's private field.

## Alternatives considered
Magic links (needs an email provider); OAuth only (judges may not have the provider); public signup (abuse).

## Consequences
Cost to reverse: Medium. See [architecture](../architecture.md).
